## 📖 Sobre o Repositório
Este repositório reúne os **desafios práticos** propostos no curso **Engenharia de Dados com Python** da [Digital Innovation One (DIO)](https://web.dio.me/).  

Os desafios consistem em construir um **sistema bancário em Python**, aplicando conceitos de lógica de programação, manipulação de dados e boas práticas em desenvolvimento.

---

## 🎯 Objetivos dos Desafios
- Exercitar **lógica de programação** com Python  
- Criar um **sistema bancário simples** com operações como:  
  - Depósito  
  - Saque  
  - Extrato  
- Evoluir o sistema para uma versão mais robusta, com:  
  - Criação de contas e usuários  
  - Registro de múltiplas contas  
  - Organização do código em funções  

---

## 📂 Estrutura do Repositório

sistema_bancario/

## 📌 Observações

Os desafios seguem a sequência proposta no curso da DIO.
Cada versão do sistema bancário adiciona novas funcionalidades e melhorias no código.
